Table

Komponen tabel dengan sort order indicator untuk header kolom. Tiga state: default, ascending, descending.

Sort Order Part

Indikator urutan kolom tabel (Sort order). Padding var(--space-050) vertikal · calc(var(--space-050) + var(--space-025) / 2) horizontal (4px × 5px). Ref: Sort order-part.png.

Default .ds-table-sort sortOrder=default · Color.Neutral.N50
Ascending .ds-table-sort--asc sortOrder=ascending · arrow up active
Descending .ds-table-sort--desc sortOrder=descending · arrow down active
Referensi Figma

Kode DS

Salin markup siap pakai. Semua kelas memakai token dari tokens.css.

table-sort.html 
<!-- Sort order: default -->
<span class="ds-table-sort" aria-hidden="true">
  <span class="ds-table-sort__chevron ds-table-sort__chevron--up"></span>
  <span class="ds-table-sort__chevron ds-table-sort__chevron--down"></span>
</span>

<!-- Sort order: ascending -->
<span class="ds-table-sort ds-table-sort--asc" aria-hidden="true">...</span>

<!-- Sort order: descending -->
<span class="ds-table-sort ds-table-sort--desc" aria-hidden="true">...</span>

<!-- Di table header (dark) -->
<th scope="col">
  Title
  <span class="ds-table-sort ds-table-sort--asc ds-table-sort--on-dark" aria-hidden="true">...</span>
</th>
