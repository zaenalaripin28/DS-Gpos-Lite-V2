Anatomy

DropdownItem
  • A. Lead icon — 24×24px, asset dari assets/icons.
  • B. Label — body small regular (--text-body-small-regular-*).
  • C. Trail icon — chevron kanan 16×16px, margin-left: auto.
  • Container — padding var(--space-100) var(--space-200), radius var(--border-radius-md).
DropdownItemRadio
  • A. Radio slot — 16×16px, border radius full, dot saat selected.
  • B. Label — body small regular, tanpa trailing chevron.
  • Container — padding & radius sama dengan DropdownItem default.
DropdownItemCheckbox
  • A. Checkbox slot — 16×16px, radius var(--border-radius-sm), icon-check.svg saat selected.
  • B. Label — body small regular, tanpa trailing chevron.
  • Container — padding & radius sama dengan DropdownItem default.

Informasi Penggunaan

Kapan digunakan

Dropdown Item adalah unit baris pada panel menu dropdown (action menu, select list, dll.). Gunakan saat satu aksi atau opsi per baris membutuhkan ikon konteks dan indikator drill-down (chevron). Untuk navigasi sidebar aplikasi, gunakan komponen Navigation Menu.

Token & layout
  • Padding vertikal var(--space-100) (8px), horizontal var(--space-200) (16px).
  • Radius var(--border-radius-md) (8px).
  • Gap antar slot var(--space-100).
  • Bungkus beberapa item dalam .ds-dropdown-menu dengan gap var(--space-050).

Do & Don't

Do (Lakukan)
  • Gunakan ikon lead yang relevan dengan label menu.
  • Pertahankan label singkat (1–3 kata) agar mudah discan.
  • Tampilkan chevron kanan hanya jika item membuka submenu atau halaman berikutnya.
  • Kelompokkan item dalam .ds-dropdown-menu per konteks panel dropdown.
Don't (Hindari)
  • Jangan hardcode warna di luar token semantic.
  • Jangan ubah padding/radius di luar spesifikasi 8×16px dan 8px radius.
  • Jangan memakai ikon eksternal di luar assets/icons.
  • Jangan menaruh terlalu banyak teks sehingga chevron terdorong keluar viewport.

Kode DS

Salin markup siap pakai. Semua kelas memakai token dari tokens.css.

dropdown-item.html 
<!-- Dropdown Button (closed) -->
<div class="ds-dropdown">
  <button type="button" class="ds-btn ds-dropdown-btn" aria-haspopup="menu" aria-expanded="false">
    Choices
    <img class="ds-dropdown-btn__chevron" src="assets/icons/icon-chevron-mini-down.svg" alt="" width="16" height="16" aria-hidden="true">
  </button>
  <div class="ds-dropdown-menu" role="menu" hidden>...</div>
</div>

<!-- Icon only open + radio scrollable menu -->
<button class="ds-btn ds-btn--icon-only ds-dropdown-btn" aria-expanded="true" aria-label="Menu pilihan">...</button>
<div class="ds-dropdown-menu ds-dropdown-menu--scrollable" role="menu">...</div>

<!-- Menu dropdown (action menu) -->
<div class="ds-dropdown-menu" role="menu">
  <button type="button" class="ds-dropdown-item" role="menuitem">
    <img class="ds-dropdown-item__lead" src="assets/icons/icon-shopping-bag.svg" alt="" width="24" height="24" aria-hidden="true">
    <span class="ds-dropdown-item__label">Option</span>
    <img class="ds-dropdown-item__trail" src="assets/icons/icon-chevron-right.svg" alt="" width="16" height="16" aria-hidden="true">
  </button>
</div>

<!-- State: selected hover -->
<button class="ds-dropdown-item ds-dropdown-item--selected-hover">...</button>

<!-- State: selected pressed -->
<button class="ds-dropdown-item ds-dropdown-item--selected-pressed">...</button>

<!-- DropdownItemRadio -->
<button type="button" class="ds-dropdown-item ds-dropdown-item--selected" role="menuitemradio" aria-checked="true">
  <span class="ds-dropdown-item__radio" aria-hidden="true"></span>
  <span class="ds-dropdown-item__label">Option</span>
</button>

<!-- DropdownItemCheckbox -->
<button type="button" class="ds-dropdown-item ds-dropdown-item--selected" role="menuitemcheckbox" aria-checked="true">
  <span class="ds-dropdown-item__checkbox" aria-hidden="true">
    <img class="ds-dropdown-item__checkbox-icon" src="assets/icons/icon-check.svg" alt="" width="12" height="12">
  </span>
  <span class="ds-dropdown-item__label">Option</span>
</button>

<!-- Menu / Default (scrollable) -->
<div class="ds-dropdown-menu ds-dropdown-menu--scrollable" role="menu">
  <!-- ulangi DropdownItem / Checkbox / Radio -->
</div>
