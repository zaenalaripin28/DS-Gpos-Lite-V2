Do & Don't

Panduan penggunaan Page Header agar konsisten dengan komponen DS yang sudah ada.

Do — Lakukan ini

  • Pilih varian sesuai kebutuhan halaman: default untuk judul saja, tambah --actions-on bila ada CTA utama.
  • Gunakan breadcrumb trail (ds-bc-container--trail) untuk hierarki navigasi.
  • Search memakai Select ds-select-trigger (variant-default); filter & sub-filter memakai ds-btn ds-dropdown-btn.
  • Jarak search–filter di toolbar: gap: var(--space-100) pada .ds-page-header__toolbar.
  • Aktifkan --subfilters-on hanya saat filter utama dibuka dan perlu baris sub-filter.

Don't — Hindari ini

  • Jangan menulis ulang style button, select, atau dropdown di dalam page header.
  • Jangan hardcode warna, radius, atau spacing — gunakan token dari tokens.css.
  • Jangan menampilkan baris sub-filter tanpa modifier --subfilters-on (varian search & filter-off).
  • Jangan mengganti Select search dengan input teks biasa atau library eksternal.
  • Jangan menambah lebih dari satu primary action di grup aksi kanan.
