Top Navigation

Top navigation responsif dari parts: logo (logo-parts.svg), .ds-btn (Akses), notification indicator (icon-bell.svg), avatar, dan menu (icon-menu.svg) untuk tablet/mobile.

variant=website
variant=tablet
variant=mobile

Informasi Penggunaan — Top Navigation

Website
Logo kiri, tombol Akses, dua notification indicator, dan avatar profil di kanan. Tanpa menu hamburger.
Tablet
Menu icon-menu.svg kiri, logo tengah, aksi kanan sama seperti website.
Mobile
Menu kiri saja — tanpa logo. Sembunyikan Akses dan notification kedua; sisakan satu bell + avatar.

Do & Don't — Top Navigation

Do — Lakukan ini
  • Gunakan modifier .ds-topnav--website, --tablet, atau --mobile sesuai breakpoint.
  • Rakit dari parts yang sudah didokumentasikan di halaman ini.
  • Tombol Akses memakai .ds-btn.ds-btn--subtle dari komponen Button.
  • Avatar dengan presence online (ds-avatar--lg).
Don't — Hindari ini
  • Jangan hardcode warna di luar token semantic.
  • Jangan menampilkan dua notification di mobile.
  • Jangan mengganti icon-menu.svg atau icon-bell.svg dengan asset lain.
  • Jangan menduplikasi markup parts — gunakan class yang sama.

Logo Parts

Logo part untuk top navigation. Asset: assets/images/logo-parts.svg. Tiga state: default, hover, press.

Default
.ds-topnav-logo — background transparan di atas top bar gelap (Color.Neutral.N900).
Hover
.ds-topnav-logo--hover — Background.Neutral.Hover → Color.Neutral.N20.
Press
.ds-topnav-logo--press — Background.Neutral.Pressed → Color.Neutral.N40.

Informasi Penggunaan — Logo

Kapan dipakai
Di pojok kiri top navigation — sebagai tautan ke beranda atau dashboard utama aplikasi GPOS Lite.
Asset
Selalu gunakan assets/images/logo-parts.svg via .ds-topnav-logo__img. Jangan merekonstruksi wordmark dari teks atau elemen grafis terpisah.
Interaksi
Bungkus dengan <a> atau <button>. Highlight hanya pada area padding logo, bukan seluruh lebar top bar.

Do & Don't — Logo

Do — Lakukan ini
  • Letakkan logo di atas latar top bar gelap (neutral-n900).
  • Gunakan state hover/press dengan token n20 / n40.
  • Sertakan aria-label yang menjelaskan tujuan tautan (mis. "GPOS Lite — beranda").
  • Pertahankan rasio aspek gambar — atur tinggi via .ds-topnav-logo__img.
Don't — Hindari ini
  • Jangan hardcode warna highlight di luar token neutral.
  • Jangan memotong atau menekan logo (distorsi aspect ratio).
  • Jangan mengganti file logo dengan versi resolusi rendah atau watermark.
  • Jangan menambahkan border atau shadow pada file logo itu sendiri.

Notification Indicator Parts

Notification indicator untuk top bar. Ikon icon-bell.svg + badge .ds-badge--important (lihat juga Icons).

Informasi Penggunaan — Notification

Kapan dipakai
Di top bar kanan — membuka panel atau halaman daftar notifikasi. Badge menampilkan jumlah item belum dibaca.
Komposisi
.ds-topnav-notif + icon-bell.svg + .ds-topnav-notif__indicator berisi .ds-badge--important.
Token warna
Badge: Background.Danger.Bold → red-r300, teks Text.Inverse → neutral-n0.

Do & Don't — Notification

Do — Lakukan ini
  • Gunakan icon-bell.svg sebagai ikon notifikasi standar.
  • Perbarui aria-label dengan jumlah unread (mis. "Notifikasi, 60 belum dibaca").
  • Sembunyikan badge bila count = 0.
  • Pakai .ds-badge--important untuk angka di atas ikon.
Don't — Hindari ini
  • Jangan hardcode warna merah di luar token danger.
  • Jangan menempatkan badge di tengah ikon — harus di pojok kanan atas.
  • Jangan menampilkan angka palsu jika tidak ada notifikasi.
  • Jangan mengganti bell dengan ikon sidebar notification lama.

Kode DS — Notification

Markup siap salin — bell + badge count.

<button type="button" class="ds-topnav-notif" aria-label="Notifikasi, 60 belum dibaca">

  <span class="ds-topnav-notif__indicator">
    <span class="ds-badge ds-badge--important">60</span>
  </span>
</button>

Footer Parts

Footer navigation untuk pager dan aksi halaman. Tombol memakai class Button DS; ikon dari assets/icons.

2/1990

Informasi Penggunaan — Footer

Kapan dipakai
Di bagian bawah layar wizard, drawer panjang, atau tabel dengan banyak halaman — untuk navigasi data dan aksi simpan/batal sekaligus.
Komposisi
Kiri: ds-footer-nav__pager (chevron + teks halaman). Kanan: ds-footer-nav__actions dengan .ds-btn--subtle dan .ds-btn--primary.
Aksesibilitas
Bungkus dengan <footer> + aria-label. Tombol chevron wajib aria-label; indikator halaman memakai aria-live="polite".

Do & Don't — Footer

Do — Lakukan ini
  • Gunakan tombol .ds-btn--primary hanya untuk aksi utama (mis. Simpan).
  • Letakkan navigasi halaman di kiri dan aksi formulir di kanan.
  • Nonaktifkan chevron prev/next di halaman pertama/terakhir.
  • Gunakan ikon icon-chevron-left / icon-chevron-right dari assets.
Don't — Hindari ini
  • Jangan hardcode warna — semua dari token semantic.
  • Jangan menempatkan lebih dari satu tombol primer di footer.
  • Jangan mengganti chevron dengan ikon custom di luar assets/icons.
  • Jangan memakai footer ini untuk navigasi global aplikasi (gunakan top nav).

Kode DS — Footer

Markup siap salin — termasuk class Button dan ikon token.

<footer class="ds-footer-nav" aria-label="Footer navigation">
  <div class="ds-footer-nav__pager">
    <div class="ds-footer-nav__nav-btns">
      <button type="button" class="ds-btn ds-btn--icon-only" aria-label="Halaman sebelumnya">
        <img src="assets/icons/icon-chevron-left.svg" alt="" aria-hidden="true">
      </button>
      <button type="button" class="ds-btn ds-btn--icon-only" aria-label="Halaman berikutnya">
        <img src="assets/icons/icon-chevron-right.svg" alt="" aria-hidden="true">
      </button>
    </div>
    <p class="ds-footer-nav__page" aria-live="polite">2/1990</p>
  </div>
  <div class="ds-footer-nav__actions">
    <button type="button" class="ds-btn ds-btn--subtle">Kembali</button>
    <button type="button" class="ds-btn ds-btn--primary">Simpan</button>
  </div>
</footer>
