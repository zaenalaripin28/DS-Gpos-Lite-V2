Range — Parts

Thumb handle slider (<RangeThumb>) — visual part 16×16px; state press memperluas hit area ke 24×24px dengan ring fokus.

state=default
.ds-range__thumb
state=hover
.ds-range__thumb--hover
state=press
.ds-range__thumb--pressed

Do & Don't

Do — Lakukan ini
  • Gunakan thumb part 16×16px; hover n300; press ring b200 pada area 24×24px.
  • Track garis memakai --color-border; saat fokus gunakan --color-blue-b200 (Border.Focused).
  • Saat ditekan, tinggi track --space-100 (8px) sesuai token spacing.
  • Posisikan fill dan thumb konsisten pada 0%, 50%, dan 100%.
  • State disabled: track --color-neutral-n20, thumb --color-neutral-n50.
  • Sertakan input type="range" native + label untuk aksesibilitas keyboard.
Don't — Hindari ini
  • Jangan hardcode warna hex — gunakan token dari tokens.css.
  • Jangan membuat slider hanya dari div tanpa input range native.
  • Jangan ubah ukuran thumb di state default/hover (tetap 16×16px).
  • Jangan gunakan track disabled untuk state aktif — hanya saat disabled.
  • Jangan menempatkan dua range berdekatan tanpa label yang membedakan fungsinya.
  • Jangan gunakan range untuk pilihan diskret sedikit — pertimbangkan radio/select.

Code — Salin Code

range.html 
<!-- value=50% default -->
<div class="ds-range ds-range--value-50 ds-range--snapshot" aria-hidden="true">
  <span class="ds-range__track">
    <span class="ds-range__fill"></span>
    <span class="ds-range__thumb-wrap"><span class="ds-range__thumb"></span></span>
  </span>
</div>

<!-- value=100% press -->
<div class="ds-range ds-range--value-100 ds-range--snapshot" aria-hidden="true">
  <span class="ds-range__track ds-range__track--pressed">...</span>
</div>

<!-- Interaktif 0–100% -->
<label class="ds-range ds-range--value-0">
  <input type="range" class="ds-range__input" min="0" max="100" value="0" step="1">
  <span class="ds-range__track" aria-hidden="true">...</span>
</label>
