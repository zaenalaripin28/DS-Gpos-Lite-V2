# Pattern: List Management Page

Purpose:
Display and manage collections of business records.

Components:
- Page Layout 
- Navigation Menu 
- Top Navigation 
- Page Header 
- Table 
- Pagination

Structure:

Page Layout
├─ Navigation Menu
├─ Top Navigation
└─ Content
   ├─ Page Header with seacrh & filter
   ├─ Table
   └─ Pagination

Required Components:
- page-layout.md (`Docs/components/page-layout.md`)
- navigation-menu.md (`Docs/components/navigation-menu.md`)
- top-bottom-navigation.md (`Docs/component/top-bottom-navigation.md`)
- page-header.md (`Docs/components/page-header.md` )
- table.md (`Docs/components/table.md`)

Optional Components:
- pagination.md (`Docs/components/pagination.md`)
- dropdown.md (`Docs/components/dropdown.md`)
- button.md (`Docs/components/button.md`)
- text-field.md (`Docs/components/text-field.md`)

Responsive:
Desktop
Tablet
Mobile

Rules:
- Never create custom layout.
- Never replace Table component.
- Never replace Navigation Menu.
